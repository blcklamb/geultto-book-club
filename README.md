# geultto-book-club

글또 5기 독서모임 레포지토리입니다

## 환경 변수

독후감 본문의 맞춤법 검사를 사용하려면 서버 환경에 `BAREUN_API_KEY`를 설정해야 합니다. 키는 클라이언트에 노출하지 않고 `/api/spellcheck`에서만 사용합니다.

검사는 기본적으로 독후감과 작성자 조합당 한 번만 사용할 수 있습니다. 로컬 개발 환경에서는 테스트를 위해 제한이 적용되지 않으며, 배포 환경에서 특정 테스트 계정을 예외로 둘 때는 해당 Supabase 사용자 UUID를 쉼표로 구분해 `SPELLCHECK_UNLIMITED_USER_IDS`에 설정합니다.
